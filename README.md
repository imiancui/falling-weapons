# Falling Weapons (v0.6)

**《BALL x PIT》×《Backpack Battles》×《靠裝勇者》**的礦坑鍛造冒險（網頁硬核挑戰版）。開局選擇 **5 位專精英雄**（矮人鐵匠・巴林／雷霆劍聖・凱爾／暗影刺客・薇拉／烈焰狂戰・伊格／極光聖女・艾莉絲），在左側打造 **7×7 鍛造背包自動產線**（雙軌合成＋鄰接遺物），右側礦坑則由英雄站在戰線向下投擲 **25 種具備獨立反彈力、投速與重量的實體武器**；移動英雄接住反彈武器即可觸發 **5 秒【強擊回投（Catch & Volley）Buff】** 與英雄專屬接球特技！支援 **🏆 10 關成長闖關模式（背包全程繼承）** 與 **♾️ 一鏡到底無盡深淵模式**！

> 玩法靈感來自 [BALL x PIT](https://store.steampowered.com/app/2062430/BALL_x_PIT/) × [vycdev/falling-pickaxe](https://github.com/vycdev/falling-pickaxe) 結合《Backpack Battles》與《靠裝勇者》。本作是網頁版原創實作，程式碼與美術素材全部原創（像素圖皆由程式生成）。

## 執行與 Tailscale 群組分享

```powershell
npm install
npm run dev        # 本機開發伺服器 http://localhost:5173
npm run build      # 型別檢查 + 產出 dist/
npm run share      # 編譯並透過 Tailscale 開放同群組連線（Ctrl+C 結束；背景執行可用 npm run share:bg）
npm run unshare    # 關閉 Tailscale 分享代理與背景伺服器（不影響其他服務）
```

同群組連線網址（僅 Tailnet 內部可連，未開公開 Funnel）：
- **手機／iPhone Safari 推薦（繞過 iCloud 私密轉送與 DNS 攔截）**：`http://100.94.165.47:5174/`
- **HTTPS 網域（同埠雙協定支援 HTTPS／HTTP）**：`https://ian-9950x3d.tailfe8b74.ts.net:5174/` 或免埠號 `https://ian-9950x3d.tailfe8b74.ts.net/`

URL 參數（測試用）：`?low` 強制低畫質｜`?nopost` 關閉後處理｜`?depth=25` 覆寫闖關深度

開發者主控台（F12 Console）：
- `fw.addGold(500)` 立即增加 500G 金幣（`fw.addTokens(5)` 增加 5 張免費擴格券）
- `fw.spawn('katar', 1.2)` 生成／強化指定武器（第 3 參數傳 `true` 可強制無視同名限制新增）
- `fw.all25()` 依序生成全部 25 把武器
- `fw.overdrive()` 立即觸發「🔥 全彈超載」讓背包全武器齊射並進入狂暴加速
- `fw.maxReso()` 將五元素共鳴直接升至滿級 Lv5（解鎖同名多把）
- `fw.setLava(4)` 將岩漿移至距離最深點 4 格處測試逼近效果
- `fw.level(5)` 跳至第 6 關（劇毒蛛后 Boss；`fw.level(9)` 為第 10 關深淵炎魔 Boss）
- `fw.startEndless()` 直接開啟無盡深淵模式

## 核心機制（詳見遊戲內 📖 Wiki）

| 雙軌合成配方 | 產物與效果 |
|---|---|
| 同款**【低階武器】＋【低階武器】** | 二合一進化為該元素**【初階武器 ★1】**（例：火把＋火把＝烈焰劍） |
| 同款**【初階武器】＋【初階武器】** | 二合一升階為該元素**【高階武器 ★1】**（例：擴散斧＋擴散斧＝震地巨錘） |
| 任意**【低／初階武器】＋【五元素魔晶】** | 跨道具鍛造出魔晶元素的**【專屬特武】**（螺旋鑽／磁暴核心／刺客拳刃／火焰刀／霜狼之爪） |
| 任意**【高階／特武】＋【五元素魔晶】** | 跨道具覺醒魔晶元素的**【傳說武器】**（泰坦巨錘／天罰雷槌／九頭蛇之牙／炎龍大劍／高星冰晶迴旋鏢） |
| 任意**【初階以上武器】＋【👑 王者聖印】** | 神聖傳說**【✨ 聖劍（Excalibur）】**（全寬十字聖光斬超高傷武器） |
| 同款同星**【高階／特武／傳說／聖劍／遺物】**二合一 | 升星突破 **★1 ➔ ★2（傷害×1.65、CD -12%）➔ ★3（傷害×2.60、CD -24%）** |

- **鄰接光環遺物（Backpack Battles 走位排陣）**：

  - `⚙️ 精密發條齒輪`（九宮格 8 格鍛造冷卻 `-22%`）

  - `🔮 共鳴增幅水晶`（十字 4 格大招速度 `+35%`、每次投射 `+3` 共鳴經驗）

- **自動鍛造產線 ＋ 拖曳精準空投 ＋ 全彈超載**：背包內武器自動充能投射，讓你隨時放手欣賞右側礦坑戰鬥；也可直接把**武器、🧨 矮人深層炸彈、🧪 女神甘露藥水**拖到右邊礦坑指定直列發動 `1.35×` 精準空投，或點擊 **「🔥 全彈超載」** 讓背包全武器同步齊射！

## 程式結構

```
src/
├─ backpack/  items.ts（25 武器＋13 遺物／魔晶／聖印／消耗品多格形狀與雙軌合成引擎）、
│             forge.ts（7×7 背包網格、鄰接光環計算、自動鍛造冷卻、跨區塊拖曳空投與商店）
├─ data/      config.ts（10 關成長、無盡參數、挖礦金幣經濟、強化卡）、weapons.ts（25 把武器完整定義）
├─ gfx/       pixel.ts（程式生成像素圖：武器、13 種遺物魔晶、符文結界石、金冠、三大首領）、particles.ts、quality.ts
├─ mine/      world.ts（物件池回收、無盡動態生成、守層結界房、首領破盾、戰術炸彈空投）、weapon.ts（25 武器＋星級與遺物加成）、
│             enemy.ts（主動巡邏 AI、金冠菁英、三大首領）、fx.ts（戰鬥特效）、renderer.ts（後處理）
├─ ui/        wiki.ts（6 分頁無障礙響應式遊戲內 Wiki：含雙軌合成配方與遺物圖鑑）
└─ main.ts    雙模式流程（闖關背包繼承）、全彈超載、挖礦經濟連動、紀錄存檔、HUD
scripts/      tailscale-server.mjs / tailscale-up.ps1 / tailscale-down.ps1 / verify_v05.mjs
```
