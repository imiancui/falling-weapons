# Falling Weapons (v0.4)

三消 × 落下武器的礦坑冒險（網頁版）。左側以 **7 格爆發行動力 ＋ 大消除連段回氣 ＋ 8 秒散熱狂暴觀賞期** 交換三消鍛造 **25 種武器**；右側放大至 58% 視野讓武器依 2D 物理墜入礦坑，自動挖礦、引爆炸藥桶、突破**守層結界房**並討伐**三大元素護盾首領**。支援 **🏆 10 關成長闖關模式** 與 **♾️ 一鏡到底無盡深淵模式**！

> 玩法靈感來自 [vycdev/falling-pickaxe](https://github.com/vycdev/falling-pickaxe)。本作是網頁版重寫，程式碼與美術素材全部原創（像素圖皆由程式生成），未使用原專案程式碼或 Minecraft 材質。

## 執行與 Tailscale 群組分享

```powershell
npm install
npm run dev        # 本機開發伺服器 http://localhost:5173
npm run build      # 型別檢查 + 產出 dist/
npm run share      # 編譯並透過 Tailscale Serve 開放 https://ian-9950x3d.tailfe8b74.ts.net:5174（僅同群組可連）
npm run unshare    # 關閉 5174 埠的 Tailscale Serve 代理（不影響其他服務）
```

URL 參數（測試用）：`?low` 強制低畫質｜`?nopost` 關閉後處理｜`?depth=25` 覆寫闖關深度｜`?nostamina` 無限行動力測試

開發者主控台（F12 Console）：
- `fw.spawn('katar', 1.2)` 生成／強化指定武器（第 3 參數傳 `true` 可強制無視同名限制新增）
- `fw.all25()` 依序生成全部 25 把武器
- `fw.overdrive()` 立即進入 8 秒散熱狂暴期（`fw.endOverdrive()` 立即結束並補滿）
- `fw.maxReso()` 將五元素共鳴直接升至滿級 Lv5（解鎖同名多把）
- `fw.setLava(4)` 將岩漿移至距離最深點 4 格處測試逼近效果
- `fw.level(5)` 跳至第 6 關（劇毒蛛后 Boss；`fw.level(9)` 為第 10 關深淵炎魔 Boss）
- `fw.startEndless()` 直接開啟無盡深淵模式

## 核心規則（詳見遊戲內 📖 Wiki）

| 單步消除條件（含連鎖） | 結果 |
|---|---|
| 同色 **3 個** | **低階武器**（碎石鎬、電擊棒、毒針、火把、冰錐） |
| 同色 **4~5 個** | **初階武器**（擴散斧、雷電刀、毒匕首、烈焰劍、寒冰長槍） |
| 同色 **6~8 個** | **高階武器**（震地巨錘、雷神戟、瘟疫鐮刀、隕石錘、冰晶迴旋鏢） |
| 同色 **9+ 個** | **傳說武器**（泰坦巨錘、天罰雷槌、九頭蛇之牙、炎龍大劍；冰為超強化冰晶迴旋鏢） |
| 全盤各色含愛心加總 **20+ 個** | **✨ 聖劍**（超高傷、聖光十字斬；壽命型每秒流失 5% HP，可用愛心補血續命） |
| 同色**累計每滿 30 個** | **累計武器**（鑽地螺旋鑽、磁暴核心、刺客拳刃、火焰刀、霜狼之爪）＋ **該元素共鳴 +1 級（最高 Lv5）** |
| **愛心** | 全體武器回血（每顆 +8%）；單步 7+ 顆額外賦予 3 秒無敵護盾 |

- **7 格爆發行動力 ＋ 大消除回氣 ＋ 8 秒散熱狂暴期**：每輪基礎 `7 格`行動力（無效交換不扣格）；單步全色總消 `8~13 顆`回氣 `+1`、`14+ 顆`回氣 `+2`（每輪最多回 4 格＝連打 11 步）並疊加狂暴蓄能。行動力歸零或點擊 **「🔥 釋放狂暴」** 即進入 **8 秒散熱狂暴觀賞期**：左側盤面暫停散熱讓你專心欣賞右側礦坑，全武器碰撞攻速 `×0.55`、大招速度 `×1.8`、全傷害 `+25%~+65%`，散熱結束瞬間**一次補滿 `7/7`**！
- **守層結界房（符文結界石）＆ 三大首領**：每隔一段深度設有橫跨全寬的**守層結界大廳**，必須擊殺頭戴金冠的**守層菁英怪（2.5× HP）**與主動巡邏怪才能震碎符文結界石繼續下潛。三大首領各自展開專屬減傷護盾：**岩石巨像**（⚡雷／💥爆／✨聖破盾）、**劇毒蛛后**（🔥火／☠爆擊破盾）、**深淵炎魔**（❄冰／✨聖破盾）。
- **雙遊戲模式**：
  - **🏆 10 關闖關模式**：第 1～10 關怪物血量從 `×1.0` 指數成長至 `×18.0`，第 3／6／10 關迎戰三大首領。
  - **♾️ 無盡深淵模式**：一鏡到底無時間限制（回收上方舊層塊維持流暢幀率），每深潛 **35m** 破結界拿三選一強化卡、每 **105m** 迎戰輪替首領；共鳴全程保留且滿 Lv5 後每 30 顆額外 `+3%` 元素專精傷害！

## 程式結構

```
src/
├─ data/      config.ts（10 關成長、無盡參數、爆發行動力、強化卡）、weapons.ts（25 把武器完整定義）
├─ gfx/       pixel.ts（程式生成像素圖：符文結界石、金冠、三大首領）、particles.ts、quality.ts
├─ match3/    logic.ts（純規則與連鎖計數）、board.ts（Three.js 三消畫面與低頻閃特效）
├─ mine/      world.ts（物件池回收、無盡動態生成、守層結界房、首領破盾）、weapon.ts（25 武器＋狂暴加速）、
│             enemy.ts（主動巡邏 AI、金冠菁英、三大首領）、fx.ts（戰鬥特效）、renderer.ts（後處理）
├─ ui/        wiki.ts（6 分頁無障礙響應式遊戲內 Wiki）
└─ main.ts    雙模式流程、7 格行動力與 8 秒狂暴期、紀錄存檔、HUD
scripts/      tailscale-up.ps1 / tailscale-down.ps1 / verify_v04.mjs
```
